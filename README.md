
# Personal Finance Tracker

A Flask-based web application to track income and expenses, generate monthly summaries, and view transactions in a tabular format.

## Live Demo
[live linnk](https://personal-finance-tracker-4wx9.onrender.com)

## Features

- Add income and expense transactions
- Monthly summary (total income, total expense, savings)
- Track recurring income
- Mark expenses as essential or non-essential
- View transactions in a Pandas-powered table
- Simple UI using Bootstrap

## Tech Stack

- Python
- Flask
- SQLite
- Bootstrap
